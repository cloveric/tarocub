Feishu/Lark First

Interactive cards, approvals, Docs comments, Sheets, Drive, groups, and threads are the primary product surface.

Four Native Engines

Codex, Claude Code, Kimi Code, and Antigravity keep their own auth, sessions, tools, skills, MCPs, and local behavior.

Durable Operations

Resume sessions, deliver artifacts, transcribe media, schedule work, inspect timelines, and coordinate multiple agents.

Operational Model

Isolated bot instances, one shared operational model.

Each bot keeps its own credentials, workspace, locks, logs, access policy, and engine sessions. The shared runtime still gives every engine the same delivery, scheduling, audit, and multi-agent semantics.

Human Factors

Feishu is the work surface, not an afterthought.

The maintainer has not used Telegram as a day-to-day control surface for a long time. TaroCub is now designed and documented Feishu/Lark-first; Telegram remains available for compatibility, not as the default path.
